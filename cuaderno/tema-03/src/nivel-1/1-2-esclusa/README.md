# 1.2 Estado de la esclusa

10 min · sin IA · nivel 1

Componente `Esclusa` con props `abierta` (booleana) y `avisos` (numero):

- «🟢 Esclusa abierta» / «🔴 Esclusa cerrada» con un ternario.
- «⚠️ Tienes N avisos pendientes» solo si hay avisos, con `&&`.
- Renderiza tres: abierta con 2, cerrada con 0, abierta con 0.

Esperado: sin avisos no aparece el parrafo… ni un 0 suelto.
