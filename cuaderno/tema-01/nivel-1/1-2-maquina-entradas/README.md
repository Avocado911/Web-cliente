# 1.2 La maquina de entradas

Nivel 1 · Calentamiento · 10 min · sin IA

## Enunciado

`crearEntrada(nombre, evento, precio = 15)` devuelve, con un template literal multilinea, una entrada formateada con el precio + 10 % de gestion calculado dentro de la interpolacion.

Salida esperada:

```
=============================

 Asistente: Ada Lovelace
 Precio final: 16.5 €
=============================
```
