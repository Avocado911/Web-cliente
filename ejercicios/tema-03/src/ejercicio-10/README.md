# Ejercicio 10 · (Reto) Refactor anti-efecto

Te damos un componente que usa `useEffect` para calcular un total a partir de una lista de precios y guardarlo en estado. Refactorizalo para eliminar el efecto y el estado redundante, calculando el total directamente durante el render. Justifica el cambio citando la idea de "You Might Not Need an Effect".
