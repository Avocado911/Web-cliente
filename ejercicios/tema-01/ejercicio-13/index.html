Ejercicio 13 - Las tres capas de un boton "Me gusta"

Describe, para un boton "Me gusta" de una red social, que parte corresponde a HTML, cual a CSS y cual a JavaScript. Explica que seguiria funcionando si JavaScript estuviera desactivado (mejora progresiva).

1. HTML: la estructura

HTML define que es el boton y que contiene: el propio boton, su texto y el contador de "me gusta". 

<form method="post" action="/publicaciones/42/me-gusta">
	<button type="submit" id="me-gusta" aria-pressed="false">
		Me gusta <span id="contador">128</span>
	</button>
</form>
  • Se usa un <button> y no un <div>: es accesible por teclado y los lectores de pantalla lo anuncian como boton.
  • aria-pressed indica si esta marcado o no (es un boton de dos estados).
  • El <form> es lo que permite que funcione sin JavaScript (ver punto 4).

2. CSS: la presentacion

CSS define como se ve: colores, forma, tamano y los distintos estados visuales. 

#me-gusta {
	border: 1px solid gray;
	border-radius: 999px;
	color: gray;
}

#me-gusta:hover {
	background-color: lightgray;
}

#me-gusta.activo {
	color: crimson;
	border-color: crimson;
}
  • Aspecto normal del boton (gris, redondeado).
  • :hover y :focus-visible: respuesta visual al pasar el raton o al llegar con el tabulador.
  • La clase .activo: como se ve cuando ya le has dado "me gusta" (en rojo). CSS define el estilo, pero no decide cuando se aplica.

3. JavaScript: el comportamiento

JavaScript define que pasa al pulsarlo, sin recargar la pagina. 

const boton = document.querySelector("#me-gusta");
const contador = document.querySelector("#contador");
let meGustas = 128;
let activo = false;

boton.addEventListener("click", (event) => {
	event.preventDefault();
	activo = !activo;
	meGustas = activo ? meGustas + 1 : meGustas - 1;

	boton.classList.toggle("activo", activo);
	boton.setAttribute("aria-pressed", activo);
	contador.textContent = meGustas;
	// Aqui se avisaria al servidor con fetch (Unidad 4)
});
  • Escucha el evento click con addEventListener.
  • preventDefault() evita que el formulario se envie y recargue la pagina.
  • Cambia el estado (activo o no), actualiza el contador con textContent y pone o quita la clase .activo con classList.
  • Avisa al servidor en segundo plano para que el "me gusta" quede guardado.

4. Sin JavaScript: mejora progresiva

Si JavaScript esta desactivado, el boton sigue viendose y sigue funcionando, aunque de forma mas basica:

  • HTML sigue ahi: el boton se muestra con su texto y su contador.
  • CSS sigue ahi: el boton tiene su aspecto y su efecto :hover.
  • Al pulsarlo, como esta dentro de un <form method="post">, el navegador envia el formulario al servidor por su cuenta. El servidor guarda el "me gusta" y devuelve la pagina actualizada.
  • Lo que se pierde es lo que aporta JavaScript: la pagina se recarga entera, no hay respuesta instantanea y el contador no cambia al momento.

Esa es la idea de la mejora progresiva: la pagina es usable solo con HTML y CSS, y JavaScript anade una experiencia mejor encima. Si el boton fuera un <div> sin formulario, sin JavaScript no haria absolutamente nada.
